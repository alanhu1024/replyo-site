安装商店版

免费安装 · Chrome Web Store · 适用于桌面网页版 X

现在能用：原文预览与粉丝徽章。回复助手和互动工作台已提交审核；下方的多样候选新设计仍在本地测试。

版本进度 · 更新于 2026 年 10 月 29 日

商店公开版：0.1.4。已提交审核：0.3.5，包含回复助手、DeepSeek 接入和本地工作台。本地测试：0.3.6，自动提供多样候选，无需预选回复类型。上述新功能尚未包含在商店公开版中。

01

看到想聊的帖子，接上话。

回复助手 · 已提交审核

在回复弹框或帖子详情页里获得回复建议。写下自己的想法，挑选、修改候选，再填入 X 回复区。

02

收到评论，看清在接哪句话。

原文预览 · 已上线

通知一多，不必逐条点进对话、往上翻。支持的回复旁直接显示它回应的原文，先看懂，再接着聊。

03

想继续的对话，留着慢慢聊。

本地工作台 · 已提交审核

把想回应的帖子和没写完的草稿保存在本机。下次打开工作台，带着上下文继续，不必重新找一遍。

下一版预览 · 多样候选正在本地测试

给你几种说法，选一句像自己的。

不用先选回复类型。Replyo 结合帖子和你的想法，给出最多四条不同角度、不同长短的候选。根据话题挑合适的说法，不为凑类型而硬聊。

  • 简短回应
  • 补充信息
  • 好奇一问
  • 另一种看法
  • 轻松调侃

轻松的帖子，可以接个梗；认真的话题，就好好聊。有不同意见，也友好地表达，让回复更像自然交流。

生成候选 → 挑选修改 → 填入 X 回复区 → 由你在 X 发布

AI 为可选功能，使用你自己的 DeepSeek API Key，用量费用由你的 DeepSeek 账户承担。Replyo 不会自动发布回复、点赞或关注。

先从看清每条回复开始。

  1. 安装商店版

    在 Chrome Web Store 添加 Replyo，插件可免费安装。

  2. 开启 Replyo

    从浏览器扩展菜单打开并启用 Replyo，按需开启原文自动加载。

  3. 打开 X 通知

    看清回复对应的原文，再进入对话接着聊。

本地整理，按需调用 AI。

原文缓存保存在本机，新版工作台的对话与草稿也保存在本机。Replyo 没有开发者运营的后台服务器，也不采集使用分析数据。

在支持 AI 的新版中，只有你主动点击“生成候选”，才会将所选帖子、可用的直接上文和你输入的想法发送给 DeepSeek。API Key 仅用于 DeepSeek 请求，不发送给 X 或 Replyo 服务器。

原文缺失时，Replyo 可能短暂打开后台 X 标签页，直接从 X 获取上下文。
